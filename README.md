# Hospital-Emergency-Room-Dashboard-Project.
This project is an interactive Excel dashboard designed to analyze hospital emergency patient data and provide useful insights into patient volume, waiting, time, satisfaction, demographics referrals.
The dashboard helps users understand key hospital performance metrics and identify patterns in patient data through interactive charts, Pivot tables, Slicers and filters.

## Key Metrics.
Total Number of Patients: 9,216
Average Patient Wait Time: 35,62
Patient satisfaction Analysis
Patient Wait Time by Gender
Patient satisfaction Score by Patient Race
Patient Referral Analysis by Age Group
Patient Admission Date Analysis

## Objectives
The main objective of this project is to transform hospital emergency data into an easy-to-understand interactive dashboard that can help stakeholders monitor patient-related KPIs and make data-driven decisions.
I created this project  because to improve  provide useful insights. This dashboard will help stakeholders monitor , analyze and make better decisions for managing patients and improving services.
